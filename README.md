# 🛠️ Docuvate

## 🎯 Overview
Docuvate is a comprehensive, privacy-first suite of client-side utilities for advanced PDF and Image processing. Built with modern web technologies, it ensures that all file operations occur locally in your browser, providing maximum security and speed without the need for server-side uploads.

## ✨ Key Features (Major v1.2 Upgrades)
- **Pro PDF Suite**: 
  - **JPG to PDF**: Advanced layout controls (A4/Letter, Margins, Fit/Fill scaling).
  - **Merge PDF**: Visual drag-and-drop reordering with page-level rotation.
  - **PDF Compare**: High-precision visual diffing with similarity index metrics.
  - **Watermark**: Advanced typography, tiling, and position presets.
- **Conversion Matrix**: 
  - **HTML to PDF/Image**: High-fidelity rendering using isolated iframe sandboxing for full CSS/JS support.
  - **OCR Scanner**: Multi-page PDF & Image text extraction with clipboard support.
- **Visual Studio**: 
  - **Photo Editor**: Advanced canvas with filters (brightness, contrast), rotation, and undo/redo.
  - **Exam Photo Resizer**: Regulatory compliant presets for Indian boards (SSC, UPSC, NEET, JEE) with auto-compression.
  - **Compress Image**: Intelligent "Target File Size" mode with before/after statistics.
- **100% Privacy**: All processing is handled client-side using WASM and local JS engines. Your data never leaves your device.
